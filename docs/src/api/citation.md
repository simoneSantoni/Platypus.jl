# Citing Platypus.jl

If you use Platypus.jl in your research, please cite the software:

> Santoni, Simone (2026). *Platypus.jl: Descriptive Atypicality in Julia*.
> https://github.com/simoneSantoni/Platypus.jl

## BibTeX

```bibtex
@misc{SantoniPlatypusJL,
  author = {Santoni, Simone},
  title = {{Platypus.jl}: Descriptive Atypicality in Julia},
  year = {2026},
  url = {https://github.com/simoneSantoni/Platypus.jl},
  note = {Homepage: https://www.bayes.citystgeorges.ac.uk/faculties-and-research/experts/simone-santoni; GitHub: https://github.com/simoneSantoni}
}
```

A machine-readable
[`CITATION.cff`](https://github.com/simoneSantoni/Platypus.jl/blob/main/CITATION.cff)
is included in the repository.

## Version and methods

Report the package version and the source commit used for your analysis alongside
this citation. These docs describe the 0.2.0 development version; they do not
announce a published release. For a working-tree analysis, preserve the source
snapshot as well as the commit identifier.

Save [`analysis_metadata`](@ref) with exported results to record the estimator,
transformation, reference weights, numerical policies, and supplied provenance.
Retain the Julia project and manifest for the dependency environment.

Cite the underlying methods you use as well as the package. The
[References](../references.md) page gives the method citations and explains which
parts Platypus implements.
